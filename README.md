# Python Text Statistics Analyzer

A simple Python application that analyzes text and provides useful statistics.

## Features

- Count total characters.
- Count total words.
- Count total sentences.
- Count total paragraphs.
- Find the most frequently used word.
- Calculate average word length.
- Handle empty input.

## Technologies

- Python 3
- Regular Expressions (`re`)
- Collections (`Counter`)

## Project Structure

```text
python-text-statistics-analyzer/
├── app.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Installation

Clone this repository:

```bash
git clone https://github.com/pradipta-web/python-text-statistics-analyzer.git
```

Navigate to the project directory:

```bash
cd python-text-statistics-analyzer
```

## Usage

Run the application:

```bash
py app.py
```

Enter your text and type `END` when finished.
